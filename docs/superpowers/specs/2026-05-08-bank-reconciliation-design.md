# 银行对账助手 - 设计文档

## Context

企业会计每月需从银行网银导出数十页 Excel 流水，与用友/金蝶财务软件中的"银行存款"明细账逐笔核对，勾对未达账项。动辄几百条记录，手工比对极易眼花勾错。

本工具旨在自动匹配银行流水与企业账务数据，输出"已达账项"、"企业已付银行未付"、"银行已收企业未收"等调节表底稿，大幅提升对账效率和准确性。

## 核心数据模型

### Transaction（交易记录）

```python
@dataclass
class Transaction:
    date: date                    # 交易日期
    amount: Decimal               # 金额
    summary: str                  # 摘要
    direction: str                # 'debit'(借/支出) 或 'credit'(贷/收入)
    balance: Optional[Decimal]    # 余额（银行流水）
    voucher_no: Optional[str]     # 凭证号（账务系统）
    source: str                   # 'bank' 或 'account'
    raw_data: dict                # 原始数据
```

### MatchResult（匹配结果）

```python
class MatchStatus(Enum):
    MATCHED = "已达账项"
    BANK_UNMATCHED = "银行未达"
    ACCOUNT_UNMATCHED = "企业未达"
    MANUAL_MATCHED = "手动匹配"
    SPLIT_MATCHED = "拆分匹配"

@dataclass
class MatchResult:
    bank_txn: Optional[Transaction]
    account_txn: Optional[Transaction]
    status: MatchStatus
    match_score: float
    match_reason: str
    split_parts: Optional[List]
```

## 匹配引擎

### 匹配流程

1. **金额精确匹配**：按金额分组，同组内进一步匹配
2. **方向一致性**：借方对借方，贷方对贷方
3. **日期模糊匹配**：日期允许 ±1 天误差
4. **摘要相似度**：使用 difflib 计算相似度，> 0.6 视为辅助匹配
5. **拆分匹配**：一条账务记录匹配多条银行流水
6. **标记未匹配**：剩余项标记为银行未达或企业未达

### 匹配规则优先级

| 优先级 | 规则 | 说明 |
|--------|------|------|
| 1 | 金额精确 | 金额必须完全一致（小数点后两位） |
| 2 | 方向一致 | 借方对借方，贷方对贷方 |
| 3 | 日期±1天 | 日期允许误差 1 天 |
| 4 | 摘要相似度 | 相似度 > 0.6 视为辅助匹配 |

## Excel 解析器

### 预定义模板

**银行流水模板**：
- 工商银行：交易日期、支出、收入、余额、摘要
- 建设银行：交易时间、借方、贷方、余额、交易摘要

**账务系统模板**：
- 用友：日期、借方、贷方、凭证号、摘要
- 金蝶：日期、借方金额、贷方金额、凭证字号、摘要

### 自定义列映射

用户可通过 GUI 配置自定义列映射，适配任意 Excel 格式。

### 数据清洗

- 日期格式统一转换为 `date` 类型
- 金额保留两位小数
- 空值处理

## 结果导出器

### 输出文件

| 文件名 | 内容 |
|--------|------|
| `对账结果.xlsx` | 银行流水+账务数据合并，含匹配状态列 |
| `余额调节表.xlsx` | 按未达账项类型分类汇总 |
| `未达账项明细.xlsx` | 所有未匹配项的详细列表 |
| `对账统计报告.xlsx` | 匹配成功率、差异统计 |

### Excel 格式化

- 添加边框
- 未达账项标黄
- 已达账项标绿

## 手动调整功能

### 功能列表

1. 查看未匹配项列表（左侧银行未达，右侧企业未达）
2. 拖拽匹配：将左侧记录拖到右侧建立匹配
3. 取消匹配：右键已匹配项，选择"取消匹配"
4. 拆分匹配：一条账务记录匹配多条银行流水
5. 匹配备注：为手动匹配添加说明
