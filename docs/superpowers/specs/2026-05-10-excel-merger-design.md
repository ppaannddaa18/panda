# Excel 多表一键合并工具箱设计文档

## 背景

季度经营分析时，需要收齐多个子公司的收入成本表进行汇总。各子公司发来的模板格式不完全一致（行顺序不同、科目名称有差异），传统方式需要逐个复制粘贴，容易出错且效率低下。

**目标**：开发一个 GUI 工具，自动读取文件夹内所有格式相近的 Excel 文件，智能匹配科目名称，合并生成标准化汇总表。

## 需求摘要

| 项目 | 内容 |
|------|------|
| 输入 | 包含多个 Excel 文件的文件夹 |
| 输出 | 合并汇总表.xlsx（科目×公司月份透视表）、未匹配项报告.xlsx |
| 数据结构 | 多公司多月份混合（每个 Excel 可能包含多个公司、多个月份的数据） |
| 识别方式 | 文件名识别公司、列标题识别科目、智能识别月份 |
| 科目映射 | 内置常用映射 + 用户可扩展 |
| 界面 | GUI 图形界面（ttkbootstrap + tkinterdnd2） |

## 数据模型

### SourceRecord

```python
@dataclass
class SourceRecord:
    """单条源数据记录"""
    company: str           # 公司名称
    month: int             # 月份 (1-12)
    account_name: str      # 原始科目名称
    standardized_name: str # 标准化科目名称
    amount: Decimal        # 金额
    source_file: str       # 来源文件路径
    sheet_name: str        # 来源 sheet 名称
```

### ParsedFile

```python
@dataclass
class ParsedFile:
    """解析后的文件数据"""
    file_path: str
    company: str                    # 从文件名识别
    sheets: List[SheetData]         # 各 sheet 数据
    parse_errors: List[str]         # 解析错误信息
```

### MergeResult

```python
@dataclass
class MergeResult:
    """合并结果"""
    records: List[SourceRecord]
    unmatched_accounts: Set[str]    # 未匹配的科目名
    pivot_table: pd.DataFrame       # 透视表结果
    statistics: Dict[str, Any]      # 统计信息
```

## 核心流程

```
1. 用户选择文件夹
       ↓
2. 遍历所有 .xlsx 文件
       ↓
3. 解析每个文件：
   - 文件名 → 公司名称
   - Sheet 名/列标题 → 月份
   - 列标题 → 科目列
       ↓
4. 提取数据生成 SourceRecord
       ↓
5. 科目名称映射标准化
       ↓
6. 生成透视表（科目 × 公司月份）
       ↓
7. 导出结果文件
```

## 智能识别策略

### 公司识别

从文件名提取公司名称，支持以下格式：
- `北京分公司.xlsx` → "北京分公司"
- `北京_2024.xlsx` → "北京"
- `2024年北京.xlsx` → "北京"
- `子公司数据/北京.xlsx` → "北京"

用户可配置命名规则模板。

### 月份识别

采用多策略依次尝试：

1. **列标题识别**：查找 "1月"、"一月"、"Jan"、"01"、"2024-01" 等模式
2. **Sheet 名称识别**：检查 sheet 名是否包含月份
3. **数据行识别**：检查首列是否为月份标识

### 科目列识别

通过列标题关键词匹配：
- 主要关键词：`科目`、`项目`、`名称`、`摘要`
- 备选关键词：`费用项目`、`成本项目`、`收支项目`

## 科目映射机制

### 内置映射表

```python
DEFAULT_ACCOUNT_MAPPING = {
    # 收入类
    "销售收入": "主营业务收入",
    "产品销售": "主营业务收入",
    "服务收入": "其他业务收入",
    # 成本类
    "销售成本": "主营业务成本",
    "产品成本": "主营业务成本",
    # 费用类
    "管理费用": "管理费用",
    "办公费": "管理费用-办公费",
    "差旅费": "管理费用-差旅费",
    "人员工资": "管理费用-工资",
    # ... 更多内置映射

```

### 映射优先级

1. 用户自定义映射（最高优先级）
2. 内置映射表
3. 原始名称（未匹配时保留）

### 映射编辑

用户可通过 GUI 添加、修改、删除映射关系，自定义映射保存为 JSON 文件。

### 科目映射编辑器

弹窗对话框，包含：
- 左侧：未匹配科目列表（来自解析结果）
- 右侧：标准科目选择 / 自定义输入
- 操作：添加映射、删除映射、保存

## 输出文件

### 合并汇总表.xlsx

- Sheet 1：透视表（科目 × 公司月份）
- 多级表头：第一级为公司，第二级为月份
- 支持小计、合计行

### 未匹配项报告.xlsx

- 列出所有未能自动匹配的科目名称
- 包含来源文件、出现次数
- 便于用户确认和补充映射

## 技术实现要点

### 依赖库

- `pandas`：数据处理、透视表生成
- `openpyxl`：Excel 读写、样式设置
- `ttkbootstrap`：现代化 GUI
- `tkinterdnd2`：拖拽支持

### 复用现有模块

| 现有模块 | 复用内容 |
|----------|----------|
| `tools/bank_reconciliation/models/` | dataclass 模式 |

| `tools/bank_reconciliation/core/exporter.py` | Excel 导出样式化 |
| `tools/bank_reconciliation/ui/file_loader.py` | 拖拽文件组件 |
| `tools/utils/helpers.py` | format_amount 等工具函数 |

### 错误处理

- 文件读取失败：记录错误，跳过该文件继续处理
- 格式识别失败：提示用户手动指定
- 科目未匹配：保留原始名称，记录到报告中
